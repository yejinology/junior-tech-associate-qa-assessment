# Postman collection

Import the collection JSON and the environment JSON into Postman.

1. Import `Restful-Booker-API-Assessment.postman_collection.json`.
2. Import `Restful-Booker-Local.postman_environment.json`.
3. Select the environment.
4. Run the collection in order.

The positive workflow stores the token and booking ID in environment variables, updates and verifies that booking, and deletes it. The negative scenarios exercise each endpoint.
